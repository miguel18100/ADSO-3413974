# G1-P2 – Actividad 05: Prototipo

## Proyecto
Sistema Gestor de Ambulancias (SGA) – SIGMAVITAL.

## Objetivo
Desarrollar progresivamente los artefactos de diseño y prototipado de la solución, tomando como referencia los requisitos funcionales, no funcionales, actores y casos de uso consolidados durante G1-P1.

## Referencias de análisis
- Caracterización de la solución.
- Requisitos funcionales y no funcionales.
- Matriz de trazabilidad de requisitos y casos de uso.
- Diagrama de casos de uso del SGA.
- Artefactos de análisis de G1-P1.

## Avances documentados
- Tres casos de uso extendidos: CU-08, CU-11 y CU-22.
- Tres diagramas de actividades: DA-01, DA-02 y DA-03.
- Modelo conceptual de dominio MD-01.
- Identificación preliminar de clases, relaciones y elementos del dominio.

- Inicio de sesión.
- Tablero operativo.
- Gestión de ambulancias.
- Gestión de personal operativo.
- Solicitudes de servicio.
- Asignación de ambulancias y personal.
- Seguimiento de servicios.
- Novedades operativas.
- Reportes e indicadores.
