# Evidencia de aprendizaje – Modelado del sistema de asistencias

## 1. Identificación

- Programa de formación: Análisis y Desarrollo de Software (ADSO).
- Proyecto formativo: Desarrollo de software orientado a servicios V2.
- Proyecto de trabajo: Sistema de asistencias de aprendices.
- Fase: Análisis.
- Evidencia: Modelado y verificación de artefactos del sistema.

## 2. Propósito

Esta carpeta reúne los artefactos elaborados para documentar, modelar y verificar el sistema de asistencias de aprendices, tomando como referencia los requisitos y el funcionamiento del proyecto de software.

## 3. Alcance del trabajo

El desarrollo de esta evidencia contempla la elaboración y revisión progresiva de:

- Diagramas de actividades.
- Casos de uso extendidos.
- Modelo conceptual.
- Modelo entidad-relación.
- Prototipos de las funcionalidades principales.
- Lista de verificación.
- Registro de ajustes.
- Matriz de trazabilidad.
- Informe de resultados.

Los artefactos se elaborarán, revisarán y documentarán progresivamente, evitando declarar verificaciones que aún no se hayan ejecutado.

## 4. Organización prevista

| Carpeta | Contenido |
|---|---|
| 01-actividades | Diagramas de actividades |
| 02-casos-uso | Casos de uso extendidos |
| 03-modelo-conceptual | Modelo conceptual del sistema |
| 04-modelo-er | Modelo entidad-relación |
| 05-prototipo | Prototipos de interfaces |
| 06-verificacion | Listas de chequeo y registro de ajustes |
| 07-trazabilidad | Matriz de trazabilidad |
| 08-informe | Informe consolidado |

## 5. Criterio de elaboración

Los artefactos se desarrollarán tomando como referencia el proyecto real de asistencia, sus requisitos, funcionalidades, estructura y datos. Las decisiones de modelado deberán mantener coherencia entre los diferentes documentos.

La verificación se documentará con evidencias reales y los cambios se registrarán mediante commits en el repositorio.

## 6. Control de versiones

Los documentos se incorporarán al repositorio mediante commits progresivos, descriptivos y correspondientes a los cambios efectivamente realizados.
